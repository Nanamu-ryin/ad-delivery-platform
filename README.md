# 广告投放平台 · 产品方案与交互原型

> 一套面向广告代理与自有投放团队的信息流广告投放管理系统方案：把「广告商 → 账户 → 渠道 → 投放计划 → AB 测试 → 落地页 → 素材 → 角色权限 → 数据看板」串成一条完整链路，解决跨账户重复录入、审核责任边界不清、指标口径不一致三个核心问题。

本仓库收录该项目的产品方案文档与交互原型说明，供评审与作品展示使用。

---

## 一、项目背景

信息流投放的实际工作状态通常是这样的：

- 同一个广告主的产品，要在多个账户、多个渠道重复建计划，字段一场一场手填；
- 落地页与素材在多个计划间反复上传，没有统一的复用与审核入口；
- 审核人员缺少统一的判定标准与违规原因枚举，驳回靠口头沟通，出了问题是「谁提的谁负责」还是「谁审的谁负责」说不清；
- 管理者想统一看消耗与转化，但各渠道、各账户的指标口径不一致，同名指标算出来的数不一样。

本方案要解决的就是这四件事：**降低跨账户跨渠道的重复操作成本、明确审核与权限的责任边界、统一数据口径、让广告主能在一个页面看到计划、消耗、线索、转化与 ROI。**

## 二、目标用户与角色

| 角色 | 核心诉求 |
| --- | --- |
| 广告主 | 随时查看名下计划的消耗、线索、转化与 ROI，判断投放是否划算 |
| 投放运营 | 快速创建与维护计划，减少跨账户重复录入，落地页与素材可复用 |
| 审核人员 | 有明确的审核依据与违规枚举，驳回可留痕、可追溯 |
| 管理者 | 掌握全局消耗与转化，按角色授权并追溯操作人 |

## 三、系统模块

系统按六个一级模块组织，模块下任一功能被勾选即可见，零勾选则隐藏并提示「暂无权限」：

| 模块 | 承载对象 | 主要能力 |
| --- | --- | --- |
| 首页 | 数据看板 | 实时数据、转化数据、数据详情 |
| 基础管理 | 广告商、账户 | 广告商与投放账户的增删改查、启停 |
| 投放管理 | 投放计划、AB 测试、访问日志 | 计划创建与维护、AB 流量分配、日志追溯 |
| 落地页管理 | 落地页 | 边池/主池分离、绑定与解绑、送审 |
| 素材库 | 图片与视频素材 | 上传、规格校验、分类与复用 |
| 账户管理 | 角色与用户 | 角色权限、模块授权、账号维护 |

## 四、关键业务规则

### 1. 边池 / 主池

落地页与素材上传后先进入**边池**，送审通过后才进入**主池**，只有主池内容才能被计划绑定。主池内容被编辑（改标题、换图、改表单字段）会退回边池重新送审。

### 2. 审核回避

- 审核人**只能审核他人提交的内容**，不能审自己提的；
- 编辑人**只能编辑本人创建的内容**，他人代改需先转交创建人并留痕。

### 3. AB 测试

- A、B 两组流量占比联动调整，**两者之和必须为 100%**；
- 单组曝光占比**最大 90%**，避免一组吃满全部流量。

### 4. 上传规格

| 类型 | 格式 | 规格 |
| --- | --- | --- |
| 图片 | jpg / png | 1000×560、1280×720、960×240、960×540、240×180 |
| 视频 | mp4 / mov / rmvb / rm | 720×1280、1080×1920、2560×1440 |

### 5. 字段约束

| 字段 | 规则 |
| --- | --- |
| 登录账号 | 字母与数字，最长 24 个字符 |
| 密码 | 数字与字母，6—15 位 |
| 联系电话 | 11 位数字 |
| 广告商名称、计划名称等 | 最长 10 个汉字（20 个字符） |
| 角色名称 | 20 个汉字 |
| 敏感内容 | 20 个汉字（40 个字符） |

### 6. 违规原因枚举

伪官方、虚假宣传、广告违禁词、非官方数据及预测、国家象征、虚构公司服务、无相关授权、恶意贬低同行。

## 五、指标口径

| 指标 | 计算方式 | 单位 |
| --- | --- | --- |
| 名片成本 | 获取的名片总数 / 全部广告投入费用 | 个/元 |
| ROI | 用户支付带来的全部收入 / 全部广告投入费用 × 100% | % |
| CTR | 广告被用户点击数量 / 广告的展现量 × 100% | % |
| 名片网销 | 名片量 / 点击量 × 100% | % |
| 日环比 | 今日数据 − 昨日数据 | 同指标单位 |

> 口径说明：名片成本在业内通用写法为「费用 ÷ 名片数」（元/个），与本方案「名片总数 ÷ 费用」（个/元）方向相反。两种写法数值互为倒数，看板上必须标注清楚是哪个方向，否则会出现「成本下降却实际变差」的误读。该条已在方案待确认清单中列出。
